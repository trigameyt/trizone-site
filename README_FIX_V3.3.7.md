# Trizone v3.3.7 — correctif tooltip Minecraft

## Correctif

Les icônes d’items Minecraft n’ajoutent plus d’attribut HTML `title` contenant l’identifiant technique (`minecraft:shield`, `minecraft:netherite_sword`, etc.).

Cela supprime la petite bulle blanche du navigateur qui apparaissait quand la souris restait sur une icône.

Le chargement item -> bloc -> barrière de secours reste inchangé.
